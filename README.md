# Stephane Dube — Professional Portfolio Website

A single-page professional portfolio for **Stephane Dube** — IT Support Specialist, AI Engineering student, and safety-focused AI developer. Built with pure HTML, CSS, and vanilla JavaScript.

**Live site:** [stephanedube.pages.dev](https://stephanedube.pages.dev)

## What's inside

- **Modern light professional theme** — clean 3D hero, responsive layout, no frameworks
- **AI chatbot demo** (`js/miniai.js`) — a real, client-side generative-bot simulation built from scratch; answers questions about skills, certifications, and experience via keyword-intent matching (~2.1.0)
- **Certifications grid** — 6 professional certificates (Microsoft, Google, IBM, Harvard CS50) with a footnote for 60+ Google badges and 29 course certificates
- **Résumé downloads** — HTML + Markdown versions
- **YouTube channel** — "White hair in tech" (AI progression videos)

## Tech

- HTML5
- CSS3 (custom properties, grid, flexbox, responsive)
- Vanilla JavaScript (no build step, no dependencies)
- Hosted on Cloudflare Pages

## Structure

```
index.html          Main portfolio page
css/style.css       Site styles
css/miniai.css      Chatbot styles
js/script.js        Page interactions
js/miniai.js        AI chatbot demo engine
Stephane_Dube.html  Résumé (HTML)
Stephane Dube.md    Résumé (Markdown)
```

## Why this exists

Presenting a real, working artifact — an AI-powered chat assistant running client-side — is stronger proof of AI literacy than a list of certificates. The chatbot demonstrates practical skills in intent matching, conversation design, and frontend engineering that map directly to AI engineering work.
